# 운전 습관 코치 기획 결정 지도

Labels: wayfinder:map

## Destination

운전 습관 점수와 사후 설명을 중심으로 공모전 제출용 서비스 기획과 핵심 시연 범위를 확정한다. 현재 운전자 대상 가치와 향후 자동주행 승차감 평가로의 확장 경로를 구체화한다.

## Notes

- 사용자가 합의한 방향: 운전 경력과 무관한 대상, 운전 중 간결한 점수 표시, 좋은 행동의 가점과 나쁜 행동의 감점, 자동 기록과 사후 복기, 어린이·노약자 동승 시 편안함 평가의 가중치 강화.
- 추가 피드백: 점수 변화 시 짧은 무음 알림을 제공하고, 드라이브별 이벤트를 자동 기록한다. 드라이브 상세에서 개별 점수 증감 요인을 설명한다. 상세 조작은 안전하게 주차된 상태에서 제공하도록 초안에 반영했다.
- 실제 부품 마모나 사람의 편안함을 측정한 것처럼 표현하지 않는다. 차량 영향은 근거 있는 교육 정보로 제공한다.
- 사용자의 추가 요청에 따라 검토용 기획안 초안을 작성한다. 초안의 미확정 수치와 기능을 결정 완료로 취급하지 않는다.
- 구현 코드는 작성하지 않는다. 중요한 결정은 단계마다 사용자와 검토한다.
- 기본 스킬: wayfinder, grilling, domain-modeling. 외부 사실 조사에는 research를 적용한다.
- 별도 이슈 트래커가 없어 local-markdown 방식을 사용한다. 초안: [서비스 기획안](../../docs/service-plan.md).

## Decisions so far

- [Pleos에서 핵심 주행 신호와 주행 중 점수 표시를 지원하는가](issues/01-platform-feasibility.md): 속도·페달 상태·조향각의 문서상 경로를 확인했다. 실차 권한·주기·가속도와 주행 화면 심사는 후속 검증 대상으로 남긴다.

## Not yet specified

- 지원 신호를 확인한 뒤 가능한 행동별 감지 기준과 실차 검증 방법.
- 실제 동승자 피드백과 주행 부드러움의 관계를 검증할 실험 설계.
- 자동주행 협력사의 요구사항과 접근 가능한 운전 주체·개입 정보에 따른 데이터 연계 범위.
- 사용자 검증 이후의 장기 이용 동기와 사업 모델.

## Out of scope

- 이번 기획에서 차량 제어, 자동주행 시스템 직접 학습·수정, 실제 부품 잔여 수명 진단을 구현하지 않는다.
- 실차에서 위험 행동을 유도해 시연하지 않는다.
